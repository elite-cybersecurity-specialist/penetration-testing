# Security Policy for This Public Repository

This repository is a **public service-information repository** for **ELITE CYBERSECURITY SPECIALIST**. It explains ECS penetration-testing services, customer-facing methodology, assessment scope and related public materials.

It is **not** a penetration-testing target, bug bounty program, authorization letter or invitation to test any ECS system or any third-party system.

## Sensitive Data or Vulnerability Disclosure

If you discover what appears to be a mistakenly published secret, private client record, credential, token or sensitive configuration in this repository, please **do not post it publicly**.

Contact:

- **Yuhisern@protonmail.com**

Please provide a minimal description sufficient to locate the issue. Do not include unnecessary secret material, do not attempt to authenticate with exposed credentials and do not expand access.

## Unauthorized Testing Notice

No testing of ECS systems, infrastructure, customer systems or connected third-party services is authorized merely because this repository is public.
